# create-boundary-cli

根据地块边界文件（CSV / KML / KMZ），生成 Shapefile 并打包为 ZIP 的命令行工具。

## 安装

```bash
# 全局安装
npm install -g @liuxspro/create-boundary-cli
# 或装到项目里
npm install -D @liuxspro/create-boundary-cli
```

## 免安装使用（npx / pnpm dlx）

一次性使用无需安装，适合偶尔转换或写进脚本/CI：

```bash
# npx
npx --yes @liuxspro/create-boundary-cli@0.2.1 地块.csv \
  --dkmc "示例地块" --dkdm "002" --xzqmc "示例区" --xzqdm "320000"

# pnpm dlx
pnpm dlx @liuxspro/create-boundary-cli 地块.csv \
  --dkmc "示例地块" --dkdm "002" --xzqmc "示例区" --xzqdm "320000"
```

- `--yes`：跳过首次下载的交互确认，非交互环境（CI/脚本）必加；
- 建议写死版本号（如 `@0.2.1`）保证可复现，不加则取最新版；
- 包内 `examples/` 目录带有示例坐标文件，安装后可在
  `node_modules/@liuxspro/create-boundary-cli/examples/` 找到。

## 用法

```bash
create-boundary <file...> --dkmc <地块名称> --dkdm <地块代码> --xzqmc <行政区名称> --xzqdm <行政区代码> [选项]
```

### 参数

| 参数        | 说明                                                                                |
| ----------- | ----------------------------------------------------------------------------------- |
| `<file...>` | 一个或多个边界文件路径，会合并为一个地块边界；传 `-` 从标准输入读取（可与文件混用） |

支持的格式：

| 扩展名 | 说明                                                                |
| ------ | ------------------------------------------------------------------- |
| `.csv` | 每行 3 列：`编号, X, Y`；首行可为标题行，也可直接是数据             |
| `.kml` | WGS84 经纬度，支持 `Polygon` / `MultiPolygon` / `LineString` 等几何 |
| `.kmz` | KML 的 ZIP 压缩包（内含 `.kml` 文件，通常是 `doc.kml`）             |

CSV 的分隔符支持逗号、制表符、分号、竖线和连续空格（从 Word 表格复制的坐标可以直接粘贴）。
坐标可为经纬度或 CGCS2000 投影坐标（需含带号，自动判断 XY 顺序）。
KML/KMZ 的经纬度会自动投影到 3 度带，带号按第一个点所在经度计算。

传多个文件时，所有多边形会合并为**一条记录、多个部件**（MultiPolygon）的 Shapefile，
面积与带号按合并后的几何重新计算。

```csv
编号,经度,纬度
1,117.513070,34.307738
2,117.513274,34.309178
3,117.514937,34.309049
4,117.514722,34.305380
5,117.510045,34.305752
6,117.510372,34.307986
```

### 必填项（对应 DBF 字段）

| 参数             | DBF 字段 | 说明       |
| ---------------- | -------- | ---------- |
| `--dkmc <名称>`  | DKMC     | 地块名称   |
| `--dkdm <代码>`  | DKDM     | 地块代码   |
| `--xzqmc <名称>` | XZQMC    | 行政区名称 |
| `--xzqdm <代码>` | XZQDM    | 行政区代码 |

### 选项

| 选项                  | 说明                                                                 | 默认值                     |
| --------------------- | -------------------------------------------------------------------- | -------------------------- |
| `-s, --stage <阶段>`  | 调查阶段：`初步调查` \| `详细调查`                                   | `初步调查`                 |
| `-o, --output <文件>` | 输出 ZIP 路径                                                        | 与第一个输入文件同目录，`{阶段}{DKDM}.zip` |
| `--ydmj <面积>`       | 用地面积 (m²)，须为正数；不填按多边形自动计算                        | 自动                       |
| `--dh <带号>`         | 带号；不填按坐标自动计算，与坐标自带带号冲突时报错                   | 自动                       |
| `--scrq <日期>`       | 生成日期，严格 `YYYY-MM-DD`                                          | 今天                       |
| `--scdw <单位>`       | 生成单位 (SCDW)                                                      | 空                         |
| `--bz <备注>`         | 备注 (BZ)                                                            | 空                         |
| `--json`              | 输出一行 JSON（`ok` / `ydmj` / `dh` / `output` / `bytes` / `warnings`） | 关                         |
| `--dry-run`           | 只校验，不写文件                                                     | 关                         |
| `-v, --version`       | 输出版本号                                                           |                            |
| `-h, --help`          | 显示帮助                                                             |                            |

### 示例

```bash
# 自动计算面积、带号，默认今天为生成日期
create-boundary examples/points.csv --dkmc "示例地块" --dkdm "002" \
  --xzqmc "示例区" --xzqdm "320000"

# KML / KMZ
create-boundary examples/地块.kml --dkmc "示例地块" --dkdm "002" \
  --xzqmc "示例区" --xzqdm "320000"
create-boundary examples/地块.kmz --dkmc "示例地块" --dkdm "002" \
  --xzqmc "示例区" --xzqdm "320000"

# 手动指定面积、带号、生成日期
create-boundary examples/points.csv --dkmc "示例地块" --dkdm "002" \
  --xzqmc "示例区" --xzqdm "320000" --ydmj 129068.42 --dh 39 --scrq 2026-09-08 \
  --scdw "XX测绘院" --bz "" -s 详细调查 -o 地块.zip

# 一次传多个文件（合并为一个地块边界）
create-boundary examples/points.csv examples/地块.kml --dkmc "示例地块" --dkdm "002" \
  --xzqmc "示例区" --xzqdm "320000"

# 从标准输入读取坐标（自动识别 CSV / KML / KMZ）
cat examples/points.csv | create-boundary - --dkmc "示例地块" --dkdm "002" \
  --xzqmc "示例区" --xzqdm "320000"
```

> 示例里的 `examples/points.csv` 是**仓库内**路径。通过 npm 安装后，同样的示例文件位于
> `node_modules/@liuxspro/create-boundary-cli/examples/`；用 npx / pnpm dlx 时请换成你自己的坐标文件路径。

## 常见错误与原因

CLI 会在库的原始报错前补上所处阶段与文件路径，并在常见坐标问题上附上提示。

| 报错信息                                                                   | 原因                                                                                    | 处理                                                                |
| -------------------------------------------------------------------------- | --------------------------------------------------------------------------------------- | ------------------------------------------------------------------- |
| `解析 地块.csv 失败: X 缺失带号`                                           | 投影坐标的 X 未含带号（整数部分不足 8 位）                                              | 补上带号，如 `39547228.491`；参见 `examples/坐标_投影 - 无带号.csv` |
| `解析 地块.csv 失败: 带号不在范围内(25~45)`                                | X 含 8 位但前两位不是合法带号                                                           | 3 度带带号应为 25~45，即 X 的前两位                                 |
| `解析 地块.csv 失败: 经度不在中国范围内(73.62~135)`                        | 经纬度输入的经度超出范围                                                                | 经度应在 73.62~135（库仅校验经度）                                  |
| `解析 地块.kml 失败: 组成环的点数至少要 3 个, 当前只有 N 个`               | KML 里的环点数不足（N 为闭合后的点数）                                                  | 至少提供 3 个点                                                     |
| `坐标点不足 3 个（当前 N 个）`                                             | CSV 数据行少于 3 行                                                                     | 补足坐标点                                                          |
| `解析 地块.kml 失败: KML 文件中为点数据`                                   | KML 里只有 `Point` / `MultiPoint`                                                       | 重新导出面状要素（`Polygon` / `LineString`）                        |
| `解析 地块.kml 失败: KML 文件中未检测到多边形数据`                         | KML 里没有可用于生成边界的几何                                                          | 确认文件内容完整，且包含面/线要素                                   |
| `解析 地块.kmz 失败: KMZ 文件中未找到 .kml 文件`                           | KMZ 压缩包内没有 KML                                                                    | 重新导出 KMZ，或用解压软件检查包内结构                              |
| `不支持的文件类型: xxx`                                                    | 扩展名不是 `.csv` / `.kml` / `.kmz`                                                     | 改用支持的文件，或把扩展名改正确                                    |
| `--xzqdm 超出 XZQDM 字段宽度（最多 12 字节，当前 16 字节；中文占 3 字节）` | 文本参数值超出 DBF 字段宽度（按 UTF-8 **字节**计）                                      | 缩短取值，或改用更短的名称/代码                                     |
| `生成边界文件失败: String length exceeds limit: N`                         | 库内部写入超宽，通常是**数值字段过大**（如 `--ydmj` 超过 14 位整数、`--dh` 超过 16 位） | 检查数值是否合理                                                    |
| `缺少必填参数: ...`                                                        | 未提供或传了空串给 `--dkmc` / `--dkdm` / `--xzqmc` / `--xzqdm`                          | 补齐四个必填参数                                                    |
| `第 N 行只有 2 列，CSV 需要 3 列`                                          | 两列坐标（缺编号列）                                                                    | 补一列序号，或导出 3 列 CSV                                         |
| `坐标跨越多个 3 度带（38, 39）`                                            | 数据里混了不同带号的投影坐标                                                            | 拆分成多个地块分别生成                                              |
| `无法得到有效面积（YDMJ=NaN）`                                             | 列数不对或几何退化                                                                      | 检查 CSV 列数 / 剔除共线点                                          |
| `--dh 40 与坐标自带带号 39 冲突`                                           | `--dh` 与坐标里的带号不一致                                                             | 去掉 `--dh`，或改用正确带号                                         |
| `参数 --scrq 需为 YYYY-MM-DD 格式`                                         | 日期格式不严格（如 `2026/11/02`）                                                       | 改成 `2026-11-02`                                                   |
| `用地面积必须为正数`                                                       | `--ydmj 0` 或负数                                                                       | 填正数，或留空自动计算                                              |
| `读取 xxx 失败: 文件不存在`                                                | 路径写错                                                                                | 检查路径                                                            |

DBF 字段宽度：文本字段（**字节**）`DKMC`/`SCDW`/`BZ` 254、`DKDM` 100、`XZQMC` 100、`XZQDM` 12；
数值字段 `YDMJ` 17 字符（2 位小数，约 14 位整数）、`DH` 16 位整数、`SCRQ` 8 位日期。
文本字段的超宽会在调用库之前被 CLI 拦下并点名参数。

退出码：`0` 成功；`1` 数据 / 几何 / 读写失败；`2` 参数错误（未知选项、必填缺失或为空、格式不合法、扩展名不支持）。
文本文件按 UTF-8 读取，失败时回退 GB18030（Excel / 旧系统导出的中文 CSV）。
输出目录不存在时会自动创建。
